Getting started

Install

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/outline-insurance/mcp/main/install.sh | bash
# Windows PowerShell
irm https://raw.githubusercontent.com/outline-insurance/mcp/main/install.ps1 | iex

The installer puts p on your PATH (on macOS and Linux by adding a marked block to your shell rc when needed — opt out with P_NO_MODIFY_PATH=1; on Windows by setting your user PATH automatically, no rc file involved), wires the MCP server into Claude Desktop via p install-desktop-config (a native merge — no jq needed), and installs the Claude Code plugin when the claude CLI is present.

Sign in

p login opens a sign-in form in your browser on your own machine (127.0.0.1) — your password never appears in the terminal or the chat, and goes only to Pathpoint. Sessions are verified with the server; when one expires, run p login again.

Check the install

p doctor prints a one-shot health report (version, session, install state) — paste it when asking for help.

Connect Claude

Three ways to bring Pathpoint into a conversation with Claude, depending on where you chat.

Claude Desktop

Wired up automatically by the installer. By hand, run p install-desktop-config — it finds the real config on every platform (including Windows MSIX installs) and merges the entry natively, no jq needed; --dry-run previews. Or edit the config yourself:

{
  "mcpServers": {
    "pathpoint": {
      "command": "/path/to/p",
      "args": ["mcp-serve"]
    }
  }
}

Claude Code

Installed automatically when the claude CLI is on your PATH. To install or update by hand:

claude plugin marketplace add https://github.com/outline-insurance/mcp.git
claude plugin install pathpoint@outline-insurance --scope user

claude.ai

The Pathpoint tools run locally, so claude.ai on its own can't reach them — use Claude Desktop or Claude Code for actual risk work. What you can add on claude.ai (and in Claude Desktop, alongside the tools) is the skill: upload pathpoint-skill.zip from the latest release under Settings → Capabilities → Skills to teach Claude the Pathpoint workflow.

Try it now — in Claude Desktop or Claude Code, ask Claude "Show me my recent Pathpoint submissions" to confirm everything is connected.

Quote a risk, start to bind

This is the whole journey — a real E&S submission from first ask to bind request, in one conversation. Claude confirms before anything is submitted or bound; you stay in control at every step.

1

Start the submission

I need a GL quote for a landscaping contractor in Austin, Texas — Hill Country Landscaping LLC.
I'll start that submission. First, a couple of basics: what's their approximate annual revenue, and do they do any structural work or tree removal above 15 feet?
Behind the scenescreate_riskget_submission_questions
Already have an ACORD? Hand Claude the file instead — it uploads it and pre-fills the application from the extraction. (upload_risk_file, get_extraction_status)
2

Answer in plain English

Around $850K in revenue. No tree work above 15 feet. Six employees, nine years in business.
Thanks — I've filled in the application and matched them to the Landscape Gardening class code. All required fields are complete. Want me to run an appetite check before we submit?
Behind the scenesmodify_submissionsearch_class_codesget_recommended_class_codes
No forms, no field names. Claude reads the live question set — labels, allowed answers, what's still required — and maps your words onto it. Ask "what's left?" any time.
3

Check appetite

Yes — check appetite.
Appetite looks good: this risk is eligible to submit as-is. One thing to know — raising the aggregate limit above $2M would send it to referral instead of instant quoting.
Behind the scenesget_appetite
Catch declines before they happen. The appetite check reads the current application and flags anything that would cause a decline or referral, so you can fix it while it's still cheap to fix.
4

Submit to markets

Looks right. Submit it.
✓ Submitted. Two instant quotes are back already — Kinsale at $4,180 and Ategrity at $4,650. One more market is reviewing and will come back by email.
Behind the scenessubmit_risk
You approve first. Claude always shows a summary of the risk and asks for an explicit yes before submitting — same as pressing Submit in the app.
5

Compare the quotes

What's the real difference between the two?
Both carry $1M per occurrence / $2M aggregate. Kinsale totals $4,712 with fees and taxes; Ategrity totals $5,204 but includes products-completed-ops at a higher sublimit. Quote letters are available for both — want them?
Behind the scenesget_riskget_quoteget_quote_documents
6

Pick one

Go with Kinsale. No terrorism coverage.
✓ Kinsale selected and TRIA declined. The bind checklist is ready — three subjectivities to clear before we can request the bind.
Behind the scenesselect_quoteset_tria
7

Clear the subjectivities

What do they need?
1) a signed application — send me the file and I'll attach it; 2) the insured's contact details — name, email, phone; 3) confirmation of no losses in the past 5 years. Give me those and I'll take care of the rest.
Behind the scenescheck_bind_readinesslist_subjectivitiesanswer_subjectivityupload_subjectivity_file
Ask "can I bind this yet?" any time — Claude re-checks readiness and tells you exactly what's still blocking, and which of your inputs clears it.
8

Request the bind

Everything's clear. To confirm: request bind on Kinsale quote #KQ-48211 — $4,180 premium, effective 9/1/2026 to 9/1/2027?
Yes, request it.
✓ Bind requested — Pathpoint's team takes it from here. Nothing else is outstanding; I'll flag it if the team needs anything more.
Behind the scenesrequest_bind
Nothing binds without you. The bind request always restates carrier, quote number, premium, and dates and waits for your explicit confirmation. If your agency routes binds through a licensed agent, Claude asks which one.

Troubleshooting & FAQ

Windows SmartScreenClick More info → Run anyway. Expected only when the download's checksum couldn't be verified (the binary is unsigned).
macOS Gatekeeperxattr -d com.apple.quarantine "$(which p)"
p: command not foundOpen a new terminal, or source your shell rc — the installer appends a marked PATH block to it. If you set P_NO_MODIFY_PATH=1, add the install directory to PATH yourself.
Checksums not verifiedThe installer couldn't fetch checksums.txt, so the download's integrity wasn't confirmed — Gatekeeper / SmartScreen will prompt before first run. Re-run the installer to retry; a checksum mismatch always fails.
Session expiredp login — it re-checks the saved session with the server and re-authenticates when it is stale
Anything elsep doctor prints a one-shot report (version, session, install health) — include it when reporting a problem
Upgradingp update installs the latest release in place (p update --check to just look)

Where do the quotes come from?

Pathpoint's markets. Some quote instantly when you submit; others are reviewed by an underwriter and come back later — ask Claude "any new quotes on this?" or check your action items.

Claude says it can't do something I expect.

Some Pathpoint capabilities are aimed at Pathpoint's internal teams and aren't loaded by default. If something you need seems missing, ask Claude to "check the available Pathpoint toolsets" — and if it's genuinely not there, it lives in the Pathpoint app.

Is my password safe?

You type it only into a sign-in form served from your own machine in your browser, and it goes only to Pathpoint. It never appears in the chat, the terminal, or any log.

Will Claude change anything without asking?

No. Submissions, quote selections, and bind requests are always summarized and confirmed with you first, and Claude reports back what actually changed.

Something else?

Run p doctor, then open an issue with the output.
