What it does

Your E&S back office, in plain English

Pathpoint is the full-service E&S wholesaler that helps commercial brokers and agents navigate E&S with confidence — and the Pathpoint MCP server brings it into Claude. Describe the risk the way you'd describe it to a colleague; Claude fills the application, checks appetite, submits to markets, and walks the quotes back to you.

Ask in plain Englishthe bundled skill teaches Claude E&S: what to ask, what each product needs, when to check appetite.
Claude does the paperworkthe application, class codes, market submission, quote comparison, subjectivities.
You stay in controlevery submission and bind request is summarized and confirmed with you first.
I need a GL quote for a landscaping contractor in Austin — Hill Country Landscaping LLC

After install

Log in and connect Claude

The installer drops the binary on your PATH (adding a marked block to your shell rc when needed — opt out with P_NO_MODIFY_PATH=1), wires the MCP server into Claude Desktop, and installs the Pathpoint plugin into Claude Code. Two steps remain. Then read the agent guide — a full quote-to-bind walkthrough.

1

Authenticate

Opens a local browser form on 127.0.0.1 with a per-run nonce — your password never touches the terminal and never leaves your machine except to call Pathpoint directly.

# Defaults to prod — your everyday Pathpoint account
p login
2

Start managing risks

Ask Claude in plain English, or call the CLI directly for scripts and CI.

p query risk --riskId "ece93c0d-…"
p schema list --filter quote

Claude Desktop config

Added automatically by the installer. By hand, run p install-desktop-config — it finds the real config on every platform (including Windows MSIX installs) and merges the entry natively, no jq needed; --dry-run previews. Or edit the config yourself:

{
  "mcpServers": {
    "pathpoint": {
      "command": "/path/to/p",
      "args": ["mcp-serve"]
    }
  }
}

Claude Code plugin

Installed automatically when the claude CLI is on your PATH — the skill plus the p mcp-serve MCP server, no separate MCP setup needed. The plugin version tracks each p release. To install or update by hand:

claude plugin marketplace add https://github.com/outline-insurance/mcp.git
claude plugin install pathpoint@outline-insurance --scope user

Claude.ai & Claude Desktop skill

Plugins are Claude Code–only, and the skill adds guidance, not tools — the Pathpoint tools run locally, so risk work needs Claude Desktop (wired up by the installer) or Claude Code. To add the skill on claude.ai or Claude Desktop: grab pathpoint-skill.zip from the latest release (the installer also stages a copy in Downloads when it detects Claude Desktop), then upload it under Settings → Capabilities → Skills → Create skill.

Troubleshooting

Windows SmartScreenClick More info → Run anyway. Expected only when the download's checksum couldn't be verified (the binary is unsigned).
macOS Gatekeeperxattr -d com.apple.quarantine "$(which p)"
p: command not foundOpen a new terminal, or source your shell rc — the installer appends a marked PATH block to it. If you set P_NO_MODIFY_PATH=1, add the install directory to PATH yourself.
Checksums not verifiedThe installer couldn't fetch checksums.txt, so the download's integrity wasn't confirmed — Gatekeeper / SmartScreen will prompt before first run. Re-run the installer to retry; a checksum mismatch always fails.
Session expiredp login — it re-checks the saved session with the server and re-authenticates when it is stale
Anything elsep doctor prints a one-shot report (version, session, install health) — include it when reporting a problem
Upgradingp update installs the latest release in place (p update --check to just look)
