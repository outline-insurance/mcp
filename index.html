What it does

Your E&S back office, in plain English

Pathpoint is the full-service E&S wholesaler that helps commercial brokers and agents navigate E&S with confidence — and the Pathpoint MCP server brings it into Claude. Describe the risk the way you'd describe it to a colleague; Claude fills the application, checks appetite, submits to markets, and walks the quotes back to you.

Connect

Add Pathpoint to Claude

The Pathpoint MCP server now runs on Pathpoint's side. There is nothing to download, update, or keep running: add the connector once and sign in. Then read the agent guide — a full quote-to-bind walkthrough.

1

Open Connectors

In Claude on the web or in the desktop app, go to Customize → Connectors. Click + Add, then Add custom connector.

2

Paste the Pathpoint URL

Name the connector Pathpoint, paste this URL, and continue through the prompts to Add.

https://mcp.app.pathpoint.com/v1
3

Sign in

Claude sends you to Pathpoint's sign-in page. Use your everyday Pathpoint login. Claude gets the same access you have in the Pathpoint app, and your password never appears in the chat.

4

Start managing risks

Ask Claude in plain English, on the web, in the desktop app, or on your phone. If Claude doesn't reach for Pathpoint, switch it on in the chat under + → Connectors.

Show me my recent Pathpoint submissions

On a Team or Enterprise plan? An Owner adds the connector once under Organization settings → Connectors. Everyone else then finds Pathpoint under Customize → Connectors and clicks Connect.

Claude Code

One command adds the hosted server. Then run /mcp inside Claude Code, choose pathpoint, and sign in in the browser.

claude mcp add --transport http --scope user pathpoint https://mcp.app.pathpoint.com/v1

Other MCP clients

Any client that supports remote MCP servers with OAuth sign-in can use the same URL.

Add the Pathpoint skill (optional)

The connector gives Claude the Pathpoint tools. The skill adds the playbook: what to ask, what each product needs, when to check appetite. Download pathpoint-plugin.zip from the latest release and upload it under Customize → Plugins → Add → Upload plugin.

Troubleshooting

Wrong accountDisconnect Pathpoint under Customize → Connectors, connect again, and sign in with the right account. Do the same if the sign-in is rejected.
Missing toolsReconnect the connector and start a new conversation. Claude keeps the tool list it saved when the chat began.
Can't add itOn Team and Enterprise plans only an Owner can add a connector. Send your Claude admin the URL above.
Attaching filesAsk Claude to attach the file. It uploads the file itself where it can, or gives you a Pathpoint upload link. Up to 50 MB per file.
Anything elseOpen an issue. The repository is public, so leave out policyholder data.
Optional

Prefer the CLI or a local server?

You don't need this to use Pathpoint in Claude. The p CLI is for scripts, CI, and anyone who wants the MCP server running on their own machine. It uses the same Pathpoint account.

1

Install

The installer drops the binary on your PATH (adding a marked block to your shell rc when needed — opt out with P_NO_MODIFY_PATH=1), wires the local MCP server into Claude Desktop, and installs the Pathpoint plugin into Claude Code.

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/outline-insurance/mcp/main/install.sh | bash
# Windows PowerShell
irm https://raw.githubusercontent.com/outline-insurance/mcp/main/install.ps1 | iex

Re-run any time to upgrade. Pin a version with P_VERSION=x.y.z.

2

Authenticate

Opens a local browser form on 127.0.0.1 with a per-run nonce — your password never touches the terminal and never leaves your machine except to call Pathpoint directly.

# Defaults to prod — your everyday Pathpoint account
p login
3

Start managing risks

Call the CLI directly for scripts and CI, or ask Claude — the local server gives it the same tools.

p query risk --riskId "ece93c0d-…"
p schema list --filter quote

Already added the hosted connector? The installer also wires a local Pathpoint server into Claude Desktop and Claude Code. Keep one or the other in each app, or Claude sees every tool twice. To drop the local one, remove the pathpoint entry from the Claude Desktop config, or run claude plugin disable pathpoint@outline-insurance.

Claude Desktop config

Added automatically by the installer. By hand, run p install-desktop-config — it finds the real config on every platform (including Windows MSIX installs) and merges the entry natively, no jq needed; --dry-run previews. Or edit the config yourself:

{
  "mcpServers": {
    "pathpoint": {
      "command": "/path/to/p",
      "args": ["mcp-serve"]
    }
  }
}

Claude Code plugin

Installed automatically when the claude CLI is on your PATH — the skill plus the p mcp-serve MCP server, no separate MCP setup needed. The plugin version tracks each p release. To install or update by hand:

claude plugin marketplace add https://github.com/outline-insurance/mcp.git
claude plugin install pathpoint@outline-insurance --scope user

Troubleshooting

Windows SmartScreenClick More info → Run anyway. Expected only when the download's checksum couldn't be verified (the binary is unsigned).
macOS Gatekeeperxattr -d com.apple.quarantine "$(which p)"
p: command not foundOpen a new terminal, or source your shell rc — the installer appends a marked PATH block to it. If you set P_NO_MODIFY_PATH=1, add the install directory to PATH yourself.
Checksums not verifiedThe installer couldn't fetch checksums.txt, so the download's integrity wasn't confirmed — Gatekeeper / SmartScreen will prompt before first run. Re-run the installer to retry; a checksum mismatch always fails.
Session expiredp login — it re-checks the saved session with the server and re-authenticates when it is stale
Anything elsep doctor prints a one-shot report (version, session, install health) — include it when reporting a problem
Upgradingp update installs the latest release in place (p update --check to just look)
